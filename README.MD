# 🐾 Voz Animal — Sistema de Denúncia de Maus-Tratos aos Animais

## 📌 Sobre o projeto

O **Voz Animal** é um sistema web desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Gestão da Tecnologia da Informação da FATEC Itu.

O projeto tem como objetivo facilitar o registro de denúncias de maus-tratos contra animais, oferecendo uma ferramenta acessível para que a população possa registrar ocorrências e obter informações que auxiliem no encaminhamento das denúncias aos órgãos responsáveis.

A iniciativa busca contribuir para a conscientização sobre a proteção animal e incentivar a participação da sociedade no combate aos maus-tratos.

## 🎯 Objetivo

Desenvolver uma plataforma que simplifique o processo de registro de denúncias, permitindo que os usuários preencham as informações da ocorrência, gerem um documento em PDF e consultem informações relacionadas à proteção animal.

## ✨ Funcionalidades

- **Registro de denúncias:** formulário para informar ocorrências de maus-tratos.
- **Denúncia anônima ou identificada:** possibilidade de registrar uma ocorrência sem informar a identidade do denunciante, conforme as opções disponíveis no sistema.
- **Classificação da ocorrência:** categorias de abandono, agressão, negligência e outros tipos de maus-tratos.
- **Geração de documento PDF:** criação de um documento com as informações registradas para download e posterior encaminhamento às autoridades competentes.
- **Mapa interativo:** visualização de informações geográficas relacionadas às ocorrências.
- **Contabilização de ocorrências:** exibição da quantidade de registros por categoria.
- **Informações de apoio:** localização de organizações e pontos de apoio à proteção animal na região de Itu.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e apresentação visual.
- **JavaScript:** funcionalidades e interatividade.
- **Leaflet:** implementação do mapa interativo.
- **Supabase:** armazenamento e consulta dos registros de denúncias.
- **Git e GitHub:** versionamento e hospedagem do código-fonte.

## 🧪 Como executar localmente

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no computador.
3. Localize o arquivo `index.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server no Visual Studio Code, caso necessário.

**Observação:** o funcionamento completo depende da configuração dos serviços utilizados pelo sistema, incluindo a conexão com o Supabase.
